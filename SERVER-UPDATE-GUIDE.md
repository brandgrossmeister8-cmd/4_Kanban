# Гайд: Как обновить файлы на сервере

## Как это работает

```
Ваш компьютер → GitHub → Сервер → Браузер
```

Когда вы меняете код:
1. **Локально** (на компьютере) меняете файлы
2. **GitHub** - пушите изменения командой `git push`
3. **Сервер** - ВРУЧНУЮ забирает изменения командой `git pull` ⚠️ **Это НЕ происходит автоматически!**
4. **Браузер** - нужно очистить кеш, чтобы увидеть изменения

---

## Быстрый алгоритм обновления

### Этап 1: Обновление на GitHub ✅

**Что делаем:** Отправляем изменения на GitHub
**Зачем:** Чтобы сервер мог их забрать

```bash
git add .
git commit -m "Описание изменений"
git push origin main
```

**Проверка:** Зайдите на `github.com/ваш-репозиторий` и убедитесь, что файлы обновились

---

### Этап 2: Обновление на сервере ⚡

**Что делаем:** Заставляем сервер забрать изменения с GitHub
**Зачем:** Сервер не обновляется автоматически - нужна команда

#### Шаг 2.1: Подключитесь к серверу

**Для Timeweb:**
1. Откройте [https://hosting.timeweb.ru/](https://hosting.timeweb.ru/)
2. Слева найдите **"Облачные серверы"**
3. Нажмите на ваш сервер
4. Нажмите кнопку **"Консоль"** или **"SSH"**
5. В консоли введите логин: `root`
6. Введите пароль (символы не будут видны - это нормально)

**Что должно получиться:** Вы увидите `root@ваш-сервер:~#`

#### Шаг 2.2: Перейдите в папку проекта

```bash
cd /var/www/canban.brandgrossmeister.ru
```

**Что должно получиться:** Путь изменится на `root@ваш-сервер:/var/www/canban.brandgrossmeister.ru#`

#### Шаг 2.3: Обновите файлы

```bash
git pull origin main
```

**Что должно получиться:** Вы увидите список обновленных файлов:
```
Updating abc1234..def5678
Fast-forward
 styles.css  | 100 +++++----
 index.html  |   2 +-
 ...
```

#### Шаг 2.4: Проверьте обновление

```bash
head -15 styles.css
```

**Что искать:**
- ✅ **Правильно:** `background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);`
- ❌ **Неправильно:** `:root { --bg-primary: #0a0e27;`

Если видите неправильный вариант - обратитесь за помощью.

---

### Этап 3: Очистка кеша браузера 🔄

**Что делаем:** Очищаем кеш браузера
**Зачем:** Браузер сохраняет старые файлы, чтобы быстрее загружать страницу

1. Откройте сайт [canban.brandgrossmeister.ru](http://canban.brandgrossmeister.ru)
2. Нажмите:
   - **Mac:** `Cmd + Shift + R`
   - **Windows/Linux:** `Ctrl + Shift + R`

**Что должно получиться:** Вы увидите обновленный дизайн

## Типичные ошибки

### ❌ "Login incorrect" при входе на сервер
**Причина:** Неправильный логин или пароль
**Решение:** Используйте реальный логин (обычно `root`) и пароль от сервера (не от GitHub!)

### ❌ "fatal: not a git repository"
**Причина:** Вы находитесь не в той папке
**Решение:** Проверьте путь командой `pwd`, должно быть `/var/www/canban.brandgrossmeister.ru`

### ❌ "Already up to date" при git pull
**Причина:** На сервере уже последняя версия
**Решение:**
1. Проверьте, что вы сделали `git push` на компьютере
2. Проверьте файлы командой `head -15 styles.css`

### ❌ Сайт не обновился после всех шагов
**Причина:** Сильное кеширование
**Решение:**
1. Откройте Developer Tools (F12)
2. Вкладка Network
3. Поставьте галочку "Disable cache"
4. Обновите страницу

## Чеклист перед обращением за помощью

Если что-то не работает, выполните эти команды и пришлите результат:

```bash
# 1. Проверка текущего коммита на сервере
cd /var/www/canban.brandgrossmeister.ru
git log -1 --oneline

# 2. Проверка дизайна в файле
head -15 styles.css

# 3. Проверка различий с GitHub
git fetch origin
git diff origin/main
```

---

## Важно запомнить

1. **Сервер НЕ обновляется автоматически** - всегда нужен `git pull`
2. **Сначала push, потом pull** - сначала отправьте на GitHub, потом забирайте на сервер
3. **Браузер кеширует файлы** - всегда очищайте кеш после обновления
4. **Проверяйте каждый этап** - не переходите к следующему, пока не убедитесь, что предыдущий работает

---

## Автоматизация (для продвинутых)

Если хотите автоматизировать обновление сервера при каждом push на GitHub, используйте GitHub Actions или Webhooks. Это требует дополнительной настройки.
