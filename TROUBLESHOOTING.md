# Решение проблем с обновлением дизайна

## Проблема: На сервере отображается старый дизайн (киберпанк) вместо нового

### Шаг 1: Диагностика

Запустите на сервере:
```bash
bash check-server.sh
```

Этот скрипт покажет:
- Текущую версию на сервере
- Версии файлов в HTML
- Какой дизайн используется в styles.css
- Различия с GitHub

### Шаг 2: Принудительное обновление

Если есть различия с GitHub:
```bash
bash force-update.sh
```

Этот скрипт:
- Сохранит ваш config.js
- Полностью сбросит файлы к версии GitHub
- Восстановит config.js

### Шаг 3: Очистка кеша браузера

**На компьютере:**
- Windows/Linux: `Ctrl + Shift + R`
- macOS: `Cmd + Shift + R`

**Или полная очистка:**
- Chrome: Settings → Privacy → Clear browsing data → Cached images and files
- Firefox: Settings → Privacy → Clear Data → Cached Web Content

### Шаг 4: Очистка кеша веб-сервера

#### Для Apache:
1. Скопируйте `.htaccess` в корень проекта (уже должен быть там)
2. Перезагрузите Apache:
   ```bash
   sudo systemctl reload apache2
   # или
   sudo service apache2 reload
   ```

#### Для Nginx:
1. Добавьте содержимое файла `nginx-no-cache.conf` в вашу конфигурацию сервера
2. Проверьте конфигурацию: `sudo nginx -t`
3. Перезагрузите Nginx:
   ```bash
   sudo systemctl reload nginx
   # или
   sudo service nginx reload
   ```

### Шаг 5: Ручная проверка

Откройте на сервере файл `styles.css` и проверьте первые строки:

**Правильная версия (классический дизайн):**
```css
body {
    font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto...
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    ...
}
```

**Неправильная версия (киберпанк):**
```css
:root {
    --bg-primary: #0a0e27;
    --neon-cyan: #00f5ff;
    ...
}
```

Если в файле киберпанк-версия, значит обновление не применилось.

### Дополнительная диагностика

**Проверить версию прямо из браузера:**
1. Откройте сайт
2. Нажмите F12 (Developer Tools)
3. Перейдите в Network
4. Обновите страницу (F5)
5. Найдите `styles.css` в списке
6. Посмотрите на параметр запроса `v=` (должно быть `v=29`)

**Проверить загруженный CSS:**
1. В Developer Tools перейдите в Sources
2. Найдите `styles.css`
3. Посмотрите содержимое - должен быть фиолетовый градиент

### Если ничего не помогло

1. **Проверьте права доступа к файлам:**
   ```bash
   ls -la styles.css
   # Файл должен быть читаемым
   ```

2. **Проверьте, что git pull действительно обновил файлы:**
   ```bash
   git log styles.css -1
   # Должен показать коммит "Восстановлен классический дизайн + удалены логи, v=29"
   ```

3. **Прямой просмотр файла на сервере:**
   ```bash
   head -20 styles.css
   # Должен показать классический дизайн
   ```

4. **Обратитесь за помощью:**
   - Пришлите вывод команды: `bash check-server.sh`
   - Скриншот страницы
   - Вывод Developer Tools → Network для styles.css
